# Napi önbevallás – üres kitöltőlap

Offline működő űrlap egy N-of-1 kutatás napi önbevallásához. Ez a repó **csak az üres kitöltőlapot**
tartalmazza; adat nincs benne, és az oldal semmit nem küld el: a kitöltött válaszok a kitöltő
telefonján és az onnan letöltött fájlban maradnak.

A kérdések forrásai az oldal alján, a saját magyar fordítás nem validált.
A forrás és a fejlesztés egy privát repóban van; ezt a repót egy szkript frissíti, kézzel ne szerkeszd.
